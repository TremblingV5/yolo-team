# Yolo-Team 前端页面与用例

## 页面总览

| 路由 | 页面 | 说明 |
|------|------|------|
| `/` | 全局看板 | 主页面，展示所有 Issue 的看板视图 |
| `/project/:key/manage` | 项目管理 | 编辑项目名称和描述 |
| `/project/:key/docs` | 项目文档列表 | 查看和管理项目文档 |
| `/doc/:key` | 文档详情 | 查看/编辑文档正文 |

> Issue 详情通过**左侧抽屉**展示，不单独占用页面路由。

---

## 1. 全局看板（`/`）

**页面描述**：系统主页面，以看板形式按 8 种状态分列展示 Issue。默认展示所有项目下的 Issue，可通过顶部分类下拉菜单按项目筛选。

### 1.1 页面布局

```
┌─────────────────────────────────────────────────────────────────┐
│ [项目: 全部项目 ▼]                        [+ 新建项目] [⚙ 管理] │
├─────────────────────────────────────────────────────────────────┤
│ 已创建 │ 方案设计 │ 方案评审 │ 代码实现 │ QA质检 │ 待审查 │ 已完成 │ 已归档 │
│ ┌────┐ │ ┌────┐  │ ┌────┐  │ ┌────┐  │ ┌────┐ │ ┌────┐ │ ┌────┐ │ ┌────┐ │
│ │    │ │ │    │  │ │    │  │ │    │  │ │    │ │ │    │ │ │    │ │ │    │ │
│ │Card│ │ │Card│  │ │Card│  │ │Card│  │ │Card│ │ │Card│ │ │Card│ │ │Card│ │
│ └────┘ │ └────┘  │ └────┘  │ └────┘  │ └────┘ │ └────┘ │ └────┘ │ └────┘ │
└─────────────────────────────────────────────────────────────────┘
                                          │ 点击卡片 ──► 左侧抽屉
                                          ▼
                               ┌─────────────────┐
                               │  Issue 详情抽屉   │
                               │  (标题/状态/…)   │
                               └─────────────────┘
```

### 1.2 看板列结构

| 列名 | 状态值 | 标识色 | 说明 |
|------|--------|--------|------|
| 已创建 | `created` | #8C8C8C（灰） | 新建任务 |
| 方案设计 | `design` | #1890FF（蓝） | 设计中 |
| 方案评审 | `review` | #722ED1（紫） | 评审关卡·CLI不可达 |
| 代码实现 | `implementation` | #FAAD14（黄） | 编码中 |
| QA质检 | `qa` | #FA8C16（橙） | 测试中 |
| 待审查 | `pending_review` | #EB2F96（粉） | Leader审查·CLI不可达 |
| 已完成 | `done` | #52C41A（绿） | 任务完成 |
| 已归档 | `archived` | #D9D9D9（浅灰） | 归档·仅页面可达 |

### 1.3 顶栏操作

| 操作 | 触发 | 说明 |
|------|------|------|
| 项目筛选 | 下拉菜单选择项目 | 选择后看板仅展示该项目的 Issue；"全部项目"恢复全局视图 |
| 新建项目 | 点击 `[+ 新建项目]` | 弹窗表单填写名称和描述，创建后自动选中新项目 |
| 项目管理 | 点击 `[⚙ 管理]` | 跳转 `/project/:key/manage`（需先选择项目） |

### 1.4 看板用例

| 编号 | 用例名称 | 描述 |
|------|----------|------|
| UC-01 | 浏览全局看板 | 默认展示所有项目下所有 Issue，8 列分状态展示。卡片显示标题、优先级标签、执行人、截至时间、仓库信息。顶级卡片可展开子卡片 |
| UC-02 | 按项目筛选 | 顶部下拉切换项目，看板动态刷新为该项目的 Issue |
| UC-03 | 创建 Issue | 在"已创建"列顶部点击"+"，弹出创建表单：标题、描述、优先级、执行人、截至时间、父卡片（可选） |
| UC-04 | 拖拽状态流转 | 将卡片从一列拖到另一列，自动触发状态变更（校验流转规则和角色权限，非法操作回弹） |
| UC-05 | 快速指派执行人 | 卡片上点击执行人位置，下拉选择执行人 |
| UC-06 | 归档卡片 | 在"已完成"列中的卡片，点击"归档"将其移入"已归档"列。仅人类可操作 |
| UC-07 | 打开 Issue 详情 | 点击卡片，左侧弹出抽屉展示完整详情 |

**数据来源**：
- 看板数据：`GET /api/v1/issues`（`?project_id=` 按项目筛选）
- 状态变更：`PUT /api/v1/issues/:key`
- 执行人列表：`GET /api/v1/executors`

## 2. Issue 详情抽屉

**交互方式**：点击看板中的卡片，从左侧弹出抽屉面板。关闭抽屉回到看板，无需页面跳转。

**抽屉内容**：

| 区域 | 内容 |
|------|------|
| 顶部 | Key 标签、状态徽章、优先级标签 |
| 编辑区 | 标题（可编辑）、描述（Markdown 编辑） |
| 属性区 | 执行人下拉、截至时间选择器、拖拽或按钮切换状态 |
| 代码仓库 | 仓库 URL、名称、分支配章（可编辑） |
| 子任务 | 子 Issue 列表，支持新建、跳转子任务 |
| 底部 | 保存修改、删除按钮 |

### 2.1 详情用例

| 编号 | 用例名称 | 描述 |
|------|----------|------|
| UC-08 | 查看详情 | 抽屉展示 Issue 所有字段：Key、标题、状态、优先级、描述（渲染）、执行人、截至时间、仓库关联、父子关系 |
| UC-09 | 编辑属性 | 在抽屉中修改标题、描述（Markdown 编辑）、优先级、执行人、截至时间 |
| UC-10 | 状态流转 | 抽屉中通过下拉或按钮变更状态。可选状态受流转规则和角色权限限制 |
| UC-11 | 关联代码仓库 | 填写/修改仓库 URL、名称、分支 |
| UC-12 | 创建子任务 | 在子任务区域点击"新建子任务"，弹出创建表单 |
| UC-13 | 查看子任务 | 子任务列表显示在父任务下方，点击可展开对应子任务的抽屉 |
| UC-14 | 删除任务 | 抽屉底部删除按钮，确认后删除（含子任务提示） |

**数据来源**：
- 详情：`GET /api/v1/issues/:key`
- 更新：`PUT /api/v1/issues/:key`
- 删除：`DELETE /api/v1/issues/:key`

## 3. 项目管理（`/project/:key/manage`）

**页面描述**：编辑单个项目的名称和描述。

| 编号 | 用例名称 | 描述 |
|------|----------|------|
| UC-15 | 编辑项目信息 | 表单编辑项目名称（≤32字符）和描述（≤128字符），保存后更新 |
| UC-16 | 返回看板 | 面包屑/返回按钮回到看板 |

**数据来源**：
- 获取：`GET /api/v1/projects/:key`
- 更新：`PUT /api/v1/projects/:key`

---

## 4. 项目文档列表（`/project/:key/docs`）

**页面描述**：展示项目下的所有文档，支持创建和删除。

| 编号 | 用例名称 | 描述 |
|------|----------|------|
| UC-17 | 浏览文档列表 | 以列表展示所有文档的 Key、标题和更新时间 |
| UC-18 | 创建文档 | 点击"新建文档"，填写标题（正文 AI 通过本地路径写入） |
| UC-19 | 进入文档详情 | 点击文档标题，跳转到 `/doc/:key` |
| UC-20 | 删除文档 | 每个文档行有删除按钮，确认后删除 |

**数据来源**：
- 列表：`GET /api/v1/projects/:key/documents`
- 创建：`POST /api/v1/projects/:key/documents`
- 删除：`DELETE /api/v1/documents/:key`

---

## 5. 文档详情（`/doc/:key`）

**页面描述**：文档的查看和编辑页面。

| 编号 | 用例名称 | 描述 |
|------|----------|------|
| UC-21 | 查看文档 | Markdown 渲染展示文档正文，显示本地文件路径供 AI 直接读写 |
| UC-22 | 编辑文档 | 切换到编辑模式，Markdown 编辑器修改标题和正文 |
| UC-23 | 保存文档 | 提交修改（更新文件 + DB 元数据） |

**数据来源**：
- 详情：`GET /api/v1/documents/:key`
- 更新：`PUT /api/v1/documents/:key`

## 页面操作路径图

```
/ (全局看板 — 主页面)
│
├── [顶栏下拉] 选择项目
│   └── 看板按项目筛选刷新
│
├── [顶栏 +新建项目] 弹窗创建项目
│   └── 创建成功后自动选中新项目
│
├── [顶栏 ⚙管理] → /project/:key/manage
│   └── 编辑项目名称与描述，[返回] 回看板
│
├── [导航栏] → /project/:key/docs
│   └── 文档列表，[点击文档] → /doc/:key
│       └── 文档查看/编辑，[返回] 回列表
│
├── [点击卡片] 左侧抽屉打开
│   ├── 查看/编辑标题、描述、优先级、执行人、截至时间
│   ├── 拖拽或按钮切换状态（受角色权限限制）
│   ├── 关联代码仓库（URL、名称、分支）
│   ├── [新建子任务] 弹窗创建子 Issue
│   ├── [点击子任务] 切换抽屉内容至对应子 Issue
│   ├── [保存] PUT 提交修改
│   ├── [删除] 确认后 DELETE（含子任务提示）
│   └── [×关闭] / [点击遮罩] 回到看板
│
├── [拖拽卡片] 看板内跨列拖拽
│   └── 自动触发状态变更，非法操作回弹
│
├── [已创建列 +按钮] 在"已创建"列顶部新建 Issue
│   └── 弹窗表单，提交后卡片出现在"已创建"列
│
└── [卡片操作] 卡片上直接操作
    ├── [点击执行人] 下拉指派
    └── [点击归档] "已完成"列卡片移入"已归档"
```

**图例**：`[操作方式]` 表示触发操作的交互方式，`→` 表示页面跳转，`└──` 表示操作结果或子操作。

## 全局操作汇总

| 操作 | 触发位置 | 说明 |
|------|----------|------|
| 新建项目 | 看板顶栏 `[+ 新建项目]` | 弹窗表单 |
| 项目筛选 | 看板顶栏下拉菜单 | 动态刷新看板 |
| 进入项目管理 | 选择项目后 `[⚙ 管理]` | 跳转 `/project/:key/manage` |
| 进入项目文档 | 看板导航 | 跳转 `/project/:key/docs` |
| 打开 Issue 抽屉 | 点击看板卡片 | 左侧弹出 |
| 关闭 Issue 抽屉 | 点击遮罩/关闭按钮 | 回到看板 |
